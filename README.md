# blake2b: community app store for Umbrel

Add this store in umbrelOS: **App Store → ⋯ (top right) → Community App Stores → paste**

```
https://github.com/christhealien/blake2b
```

| App | What |
|---|---|
| **Blake2b ASIC Control** | Fleet dashboard, presets, schedules and a per-chip auto-tuner for Blake2b miners. Source: [blake2b-asic-control](https://github.com/christhealien/blake2b-asic-control) |
| **DATUM Gateway (blake2b)** | DATUM Gateway on your own node with a redesigned dashboard, one sign-in, best share per miner. Source: [datum-gateway-umbrel](https://github.com/christhealien/datum-gateway-umbrel) |
| **Mempool (blake2b)** | Block explorer (the mempool.guide fork) on your own node, in the same theme, with Blockchain Bandit blocks in gold. Source: [mempool-umbrel](https://github.com/christhealien/mempool-umbrel) |

This repo only holds the Umbrel app folders (manifest, compose, icon, screenshots). The images are built from the
source repos and pulled from ghcr.io.
